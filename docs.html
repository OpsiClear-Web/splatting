Get started

splatting is a 3DGS & 4DGS viewer for iPhone. It needs iOS 27 or later. No account required.

Add captures

Tap + to add a file, a folder or a link. A folder of numbered frames plays as an animation. Imported files stay on your iPhone.

Supported formats (limits depend on the format and your iPhone):

  • GSAV
  • Gaussian PLY
  • Compressed PLY
  • SPLAT
  • SPZ
  • SOG v2
  • NPZ
  • FTGS PLY
  • TSOG

View in your room

AR uses ARKit and needs camera access. LiDAR helps find surfaces but is optional.

  1. Open AR. Tap the capture to open it in AR.
  2. Find the floor. Point your iPhone at the floor and move slowly.
  3. Place it. Tap a floor or table to place the capture.

Tips

  • Aim at a textured surface in good light.
  • Move slowly.
  • If AR is interrupted, return to the same part of the room, or reset AR tracking.

In your browser

Drop .gsav or .ply files, or a folder of them, on 4d-t.win. Numbered PLY frames play at 30 fps. Files stay on your device.

The browser opens GSAV and Gaussian PLY only. Other formats need the iPhone app.

Open source

Our public Gaussian splatting tools, free under their licenses. Open an issue if something breaks.

gsply

MIT

Read and write Gaussian splat PLY files in Python, about 93 million Gaussians a second. Compressed PLY and optional GPU support.

pip install gsply
from gsply import plyread

data = plyread("model.ply")   # standard or compressed PLY
data.means                    # (N, 3) positions
data.save("small.ply", compressed=True)

KissGsVanilla

Apache-2.0

An independent KISS‑GS compression pipeline that writes SOG v2 for PlayCanvas. Not affiliated with the paper’s authors.

git clone https://github.com/OpsiClear/KissGsVanilla.git

fussim

MIT

Fused SSIM for PyTorch, usable as a training loss. Prebuilt wheels for NVIDIA GPUs.

pip install fussim

flash-kmeans-cuda

MIT

CUDA kernels for batched K‑Means on NVIDIA GPUs, with the flash‑kmeans API.

git clone --recursive https://github.com/OpsiClear/flash-kmeans-cuda.git

GMMXX

MIT

Gaussian mixture models on the GPU in PyTorch, with a scikit‑learn-style API.

git clone https://github.com/OpsiClear/GMMXX.git

FlashImgs

AGPL-3.0

Fits an image as 2D Gaussians in seconds and renders at over 12,000 fps.

git clone https://github.com/OpsiClear/flashimgs-clean.git
